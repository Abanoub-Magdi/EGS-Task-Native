# EGS Task - Native Web Application

A native HTML, CSS, and JavaScript web application assignment showcasing a modern company website for EGS. This project demonstrates proficiency in front-end web development using only vanilla web technologies without any frameworks or libraries.

## 📋 Description

**EGS Task Native** is a comprehensive multi-page website assignment built entirely with native web technologies. The project features a professional company website layout with multiple sections including hero sections, company capabilities, testimonials, and company culture pages. This demonstrates core web development skills using pure HTML5, CSS3, and JavaScript.

## ✨ Features

- 🎨 **Modern Design**: Clean, professional layout with responsive design
- 📱 **Responsive Layout**: Works seamlessly across desktop, tablet, and mobile devices
- 🏢 **Company Sections**: Multiple pages showcasing company information
  - Hero section with compelling visuals
  - Company capabilities and services
  - Client testimonials
  - Company culture and life at EGS
- ⚡ **Native JavaScript**: Interactive features implemented with vanilla JavaScript
- 🎯 **No Dependencies**: Built without any external frameworks or libraries
- 📄 **Multi-Page Structure**: Organized folder structure for different sections

## 🛠️ Technologies Used

- **HTML5**: Semantic markup and structure
- **CSS3**: Modern styling, animations, and responsive design
- **JavaScript (ES6+)**: Interactive functionality and dynamic content
- **Custom Fonts**: Local font files for typography

## 📦 Installation

1. Clone this repository:
\`\`\`bash
git clone https://github.com/Abanoub-Magdi/EGS-Task-Native.git
cd EGS-Task-Native
\`\`\`

2. Open \`index.html\` in your web browser:
\`\`\`bash
# Using a local server (recommended)
python -m http.server 8000
# Then visit http://localhost:8000
\`\`\`

Or simply open \`index.html\` directly in your browser.
